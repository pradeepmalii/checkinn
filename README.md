# CheckInn 

CheckInn is a Hotel Booking and Management System built using Java Spring Boot.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Lombok

## Features (Planned)
- User Authentication
- Hotel Management
- Room Management
- Inventory Management
- Hotel Search
- Booking Management
- Payment Integration
- Dynamic Pricing

> This project is currently under development.
